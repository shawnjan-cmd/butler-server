# BUTLER AI: PC Automation Server

> **butler-server** — The backend engine powering Butler AI's remote PC automation suite.

## Overview

Butler AI Server is the proprietary PC-side daemon that transforms your desktop into a remotely commandable machine. It handles secure command routing, real-time system monitoring, AI chat with full context history, knowledge base auto-expansion, and self-healing execution — all accessible from your phone or any connected client.
